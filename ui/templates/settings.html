Host telemetry mapping

Optional overrides for the AMUD agent. Leave blank for automatic detection. Changes apply on the next agent config sync (save settings, then wait a few seconds). If mounts or interfaces are not visible inside the agent container, the agent falls back to auto-detect and admins see an (auto-detect) hint on the dashboard.

How to find your interface names and disk mounts → (Proxmox, Unraid, Docker)

Comma-separated interface names counted as external bandwidth on the dashboard. Names are case-insensitive and duplicates are ignored.

Comma-separated interface names counted as internal bandwidth (bridges, Docker, etc.). Names are case-insensitive and duplicates are ignored.

Comma-separated mount paths for storage usage (e.g. Unraid array /mnt/user or cache pool only). Paths are matched by prefix and normalised (trailing slashes and duplicates are ignored).
